Criteri de lectura

La tècnica no substitueix la pregunta. El circle packing prioritza la pertinença jeràrquica; el dendrograma, la semblança entre perfils; i el violí, la forma de les distribucions. Les pàgines expliquen què codifica cada marca, quines transformacions s’han fet i on acaba la interpretació legítima.

Les dades són instantànies històriques o mostres delimitades. Les xifres i conclusions fan referència als països, anys i registres descrits a cada pàgina.

Dades preparades i gràfics generats amb el codi del repositori. Consulta el README del projecte per reproduir-los.
